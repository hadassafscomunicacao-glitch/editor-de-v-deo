# Editor de vídeo — "O elevador do conflito"

Pós-produção completa da aula *O elevador do conflito* (Método Cultura em Ação · Indira Matos e Hellen de Paula).

Tudo o que foi entregue está em [`entrega/`](entrega/):

| Arquivo | Conteúdo |
|---|---|
| `Video_Final.mp4` | edição completa: cortes, color grading, motion graphics, áudio tratado e legendas (H.264, ~400 MB, pronto para publicar) |
| `Video_Sem_Legendas.mp4` | a mesma edição, sem legendas gravadas na imagem |
| `*_master.mp4` | masters de arquivo em bitrate mais alto (~1 GB cada), gerados direto do bruto |
| `Legendas.srt` | legendas sincronizadas com a versão final |
| `Relatorio_Edicao.md` | intervenções, timestamps das animações e limitações técnicas |
| `Projeto_Editavel/` | scripts, cenas de animação, mapa de edição, LUTs, fontes, efeitos sonoros e transcrições |

Os vídeos (`*.mp4`) não vão para o Git por causa do tamanho; eles são entregues diretamente. As versões de entrega foram recodificadas do master com x264 preset slow, CRF 21, e ficaram visualmente idênticas ao master (SSIM 0,995).
